# AGUI WebChat

A Blazor Server (.NET 10) chat application featuring Fluent UI, an Ollama agent exposed through AG-UI, SignalR telemetry, and an AI model catalogue backed by SQL Server.

## Documentation

- [Project guide](docs/README.md): setup, configuration, building, and testing.
- [Architecture](docs/ARCHITECTURE.md): application components and communication flows.

## Repository Structure

- `src/`: client, server, shared contracts, and middleware.
- `tests/`: automated tests.
- `docs/`: detailed documentation.

Open `AGUIWebChat.slnx` to work with the solution.
